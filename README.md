# Annem Suhas Reddy — Portfolio

A premium, responsive portfolio website showcasing my projects, skills, and journey as a B.Tech CSE student and app developer.

🔗 **Live**: [suhas2006-code.github.io/portfolio](https://suhas2006-code.github.io/portfolio/)

## ✨ Features

- **Clean White & Orange** design with floating pill navbar and bento-grid layouts
- Particle background, animated gradient text, and typewriter effect
- Split hero layout with squircle profile photo and animated border
- Scrolling tech ticker marquee and interactive project cards
- Horizontal journey timeline with phase-numbered cards
- Animated stat counters, 3D tilt cards, and scroll-reveal effects
- Fully responsive (desktop → tablet → mobile)

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Structure | HTML5, Semantic Elements |
| Styling | Vanilla CSS, Bento Grid, CSS Animations |
| Interactivity | Vanilla JavaScript (IntersectionObserver, Canvas particles) |
| Fonts | Google Fonts (Inter, Outfit) |
| Hosting | GitHub Pages |

## 📁 Structure

```
portfolio/

├── script.js       # Animations, particles, and interactions
├── profile.png     # Profile photo

```

## 🚀 Run Locally

```bash
# Clone
git clone https://github.com/suhas2006-code/portfolio.git
cd portfolio

# Serve (any static server works)
python -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000)
